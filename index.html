MakerCode AI talks to Google's Gemini API straight from your browser, so you use your own free key. It is saved in this browser only and is never sent anywhere except Google.

  1. Open aistudio.google.com/apikey and sign in with a Google account.
  2. Click Create API key, then copy it.
  3. Paste it above and press Test key.

On a shared school computer, open Settings and press Forget key before you leave. In class, give every student their own key: one shared key hits its rate limit fast.

How to use MakerCode AI

Getting started

  1. Pick your board. Change it any time with the Change button.
  2. Add your own Gemini API key in Settings.
  3. Describe what you want to build in your own words.
  4. Read the Checks panel before you wire anything up.

The three modes

  • Socratic is the default. One question at a time, hints that get stronger, and the solution stays locked until you have made a real attempt.
  • Build gives the complete solution with the reasoning and testing steps.
  • Ask is for quick questions with no project plan attached.

What this app does not do

  • It does not compile. Code is always marked Not compiled.
  • It does not flash your board. Download the file and open it in MakeCode, the MicroPython editor or the Arduino IDE.
  • It cannot tell you wiring is safe from a photo. It says what it can see and what is unclear.

Using it with a class

Every student needs their own API key, or one shared key hits its rate limit within minutes. Chats are saved in the browser they were made in, so export the JSON to move work to another machine.

Responsible use

  • AI-generated code can be wrong. Check the wiring before applying power.
  • Test one function at a time.
  • A teacher should review anything involving mains, heat, motors or lithium cells.
  • Do not put personal information in prompts, and do not upload photos with identifiable students without consent and approval.
