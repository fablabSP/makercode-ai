How to use MakerCode AI

Getting started

  1. Pick your board, language and level in the top bar.
  2. Add a Gemini API key in Settings. Without one you get the offline example only.
  3. Describe what you want to build in your own words.
  4. Socratic Mode starts on. Switch it off in the top bar, or in Settings, for full solutions.
  5. Read the plan and the pin checks before you wire anything.

Socratic Mode

This is on by default. The assistant does not hand over answers. It asks one question at a time and works through trigger, input, decision, output, structure, component, pin, test, edge case and improvement. Hints get stronger each time you ask. Show solution unlocks once you have made an attempt.

What this app does not do

  • It does not compile code. Anything shown is marked as not yet compiled.
  • It does not flash your board. Download the file and use MakeCode or the Arduino IDE.
  • It cannot confirm that wiring is safe from a photograph.

Using it in class

Each student needs their own API key, or one shared key will hit its rate limit quickly. Projects save to the browser they were made in and do not follow a student to another machine — export the JSON to move work.

Responsible use

  • AI-generated code can contain mistakes. Verify wiring before applying power.
  • Test one function at a time.
  • A teacher should review anything safety critical, including mains, heat, motors and lithium cells.
  • Do not put personal information in prompts.
  • Do not upload images showing identifiable students without consent and approval.
